## 1. 评审项与结论

### 1.1 P016 会话 token（agent-service + 主进程）

| 检查项 | 结论 |
|---|---|
| POST /v1/authorize 鉴权 | ✅ 仅进程级 token 可调用（bootstrap）；sessionId 白名单校验（R007 同源） |
| 轮换语义 | ✅ 再调用即旧 token 失效；timingSafeEqual 常量时间比对（防时序侧信道） |
| 绑定校验 | ✅ run 按 body.sessionId 绑定；stream/cancel 经 RunManager.requestId→sessionId 解析绑定 |
| 存在性泄露 | ✅ 未知 requestId + 会话 token → 401（不泄露是否存在，404 仅进程级 token 可见） |
| health/metrics | ✅ 仅进程级 token（README 登记）；会话 token 读取进程级信息被拒 |
| 兼容并存 | ✅ 进程级 token 旧路径可用（已登记废弃）；主进程 401→刷新→重试→回退链有边界 |
| 渲染层隔离 | ✅ 会话 token 仅主进程内存 Map；preload 不暴露；不持久化；网关重启即清空 |

### 1.2 P016 KeyStore（packages/keystore）

| 检查项 | 结论 |
|---|---|
| KDF | ✅ scrypt N=16384/r=8/p=1（OWASP 2023 下限），storeSalt 随机 16B |
| 加密 | ✅ AES-256-GCM，随机 12B IV，AAD=keyRef（条目互换攻击测试覆盖） |
| fail-closed | ✅ 篡改/错口令/损坏文件/未知版本 → KeyStoreError，不返回猜测明文 |
| 凭据语义 | ✅ sandbox-launcher scrubEnv 对 `*KEY*/*TOKEN*/*SECRET*` 等硬剥离，extras 放行也拒绝 |

### 1.3 P015 sandbox-launcher（P002-SP 真机结论背书）

| 检查项 | 结论 |
|---|---|
| 真机结论 | ✅ 具体且诚实：受限令牌仅去管理员化；低完整性需管理员（exit=5 实测）；AppContainer 需 native helper |
| 策略 fail-closed | ✅ 空根/相对路径/放开网络与能力均拒绝（原始值校验，非 resolve 后） |
